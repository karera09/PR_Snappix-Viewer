# Snappix Viewer

ローカルフォルダ・ネットワークフォルダ（NAS）を問わず、**大量の画像をスムーズに閲覧・検索・整理**するための Windows 用ポータブル画像ビューアーです。

## 特長

### 大規模ライブラリでも軽い
- 数十万枚規模のライブラリを想定した非同期スキャンと多層キャッシュ（サムネイル・フォルダプレビュー・検索索引をディスクに永続化。再訪問・再起動後も即表示）
- NAS（SMB）向けの並列度チューニングとパフォーマンスプリセット
- 行詰めレイアウト（justified）/ 正方形グリッドの切替、タッチスクロール対応

### 強力な検索
- ファイル名検索（索引 + ライブ走査の並行実行で、索引が古くても結果は常に正しい）・投稿本文の検索（`body:` 構文）
- 投稿タグ・タイトル・お気に入り数などによる絞り込み構文（post.md 対応ライブラリ）
- スター・ユーザータグ・「あとで見る」による自分だけの絞り込み

### 閲覧・整理
- 画像 / 動画 / 音声 / PDF / Markdown / テキスト / ZIP（ドリルイン展開）のプレビュー
- 全画面ライトボックス・スライドショー・ズーム保持・ミニマップ
- スター・ユーザータグ・あとで見る・ブックマークによるキュレーション
- ドラッグ & ドロップでの書き出し

### ポータブル & プライバシー
- インストール不要。レジストリ・%APPDATA% に書き込まず、全データはフォルダ内で完結
- テレメトリなし（利用状況の外部送信は行いません）

### プラグインで拡張できる
- `plugins/` フォルダにプラグインを置くだけで機能を追加できます（作り方は同梱の `plugins/PLUGIN_DEVELOPMENT.md`）
- プラグインには、それぞれ固有の利用条件・ライセンス表記が付属する場合があります

## クイックスタート

1. 配布フォルダを任意の場所に展開する
2. `SnappixViewer.exe` を起動（初回に利用規約への同意が必要）
3. 「フォルダを開く」(Ctrl+O) で画像のあるフォルダを開く

## フォルダ構成

```
snappix-viewer/
├── SnappixViewer.exe       ← ビューアー本体
├── plugins/                ← プラグインを置くフォルダ
│   └── PLUGIN_DEVELOPMENT.md
├── data/                   ← 設定・キャッシュ（初回起動時に生成）
├── library/                ← 既定の閲覧フォルダ（任意のフォルダを開けます）
├── docs/                   ← フォーマット仕様
├── THIRD_PARTY_LICENSES.txt
└── 利用規約・免責事項.txt
```

## post.md 対応（オプショナル拡張）

フォルダに `post.md`（メタデータファイル）がある場合、投稿タイトル・投稿日・タグ・お気に入り数などの表示、投稿日ソート、本文プレビュー・本文検索、ライブラリ健全性チェックなどの**追加機能が自動的に解放**されます。無くても通常の閲覧機能はすべて使えます。

対応フォーマットの仕様は [docs/formats/post-md.md](docs/formats/post-md.md) を参照してください（外部ツールがこの仕様で書き出せば、そのライブラリをフル機能で閲覧できます）。

## 動作環境

- Windows 10 バージョン 1703（Creators Update）以降 / Windows 11 (64bit)
  - 同梱の Qt が OS 側の `icuuc.dll` を必要とします（Windows へ標準搭載されたのは Windows 10 バージョン 1703 から）。それより前の Windows 10 では起動できません

## 配布物の出どころと検証

- 最終版の配布 zip（`snappix-viewer-v<版数>.zip`）は、この公開リポジトリの GitHub Actions（`.github/workflows/build-release.yml`）が版数タグごとにビルドして Release に添付したものです。手元でビルドした物は配布しません
- 各 zip には来歴証明（GitHub Artifact Attestations）が付きます。GitHub CLI で、その zip がこのリポジトリのどのコミット・どの実行から作られたかを検証できます

```
gh attestation verify snappix-viewer-v<版数>.zip --repo karera09/PR_Snappix-Viewer
```

- 同じ木から自分でビルドすることもできます（Windows。`build.bat` を実行すると成果物が `dist/` に置かれます）
